# sentry-landing

The marketing site for **Chipmo Sentry** — a single-page funnel that explains AI loss-prevention to a
Mongolian retailer in a few seconds and captures a demo request. Mongolian primary, English via `?lang=en`.

Astro 5 (SSR, Node adapter) · Tailwind v4 · `@astrojs/sitemap` · Apache-2.0

Live: `sentry-landing-production.up.railway.app` (auto-deploys on push via GitHub Actions).

---

## What ships

- **Single-page funnel** (`index.astro`): Hero → Risks → How it works → Business value → Use cases →
  Pricing → FAQ → demo CTA. Section order is tuned for 3–5 second comprehension.
- **Positioning:** focused on **retail shoplifting / loss prevention** (not a broad AI platform) — uses the
  customer's existing cameras, per-camera pricing, real-time alerts, VLM-verified events.
- **Pricing:** Starter 25,000₮ / Pro 50,000₮ (highlighted) / Enterprise (custom), per camera / month.
- **Lead capture** (`src/pages/api/lead.ts`): name / org / phone / email / camera-count / industry →
  forwards to the backend `POST /api/v1/leads` (which persists it + pings the founder on Telegram).
  Defends with a hidden **honeypot** field + per-IP rate limiting; invalid email degrades gracefully to
  `?form=error`; backend downtime never loses the lead (it falls back to a stdout log).
- **Bilingual:** all copy lives in `src/lib/content.ts` as `T("mn", "en")` pairs; a header toggle swaps
  `?lang=en`. No `/en/*` routing yet (kept simple for launch).
- **SEO:** canonical URLs, OG/Twitter cards (1200×630 OG image generated by `scripts/generate-og.mjs`),
  auto sitemap, robots.txt. Brand tokens mirror [sentry-ui-kit](https://github.com/Chipmo-Sentry/sentry-ui-kit)
  (`#F97316` + slate) without a React dependency.
- **Legal:** `privacy.astro`, `terms.astro`, and a `thank-you.astro` confirmation (noindex).

## Quick start

```bash
npm install
cp .env.example .env       # PUBLIC_SITE_URL, SENTRY_BACKEND_URL
npm run dev                # → http://localhost:4321
```

Scripts: `dev` · `build` (Astro SSR → `dist/server/entry.mjs`) · `preview` · `start` · `typecheck`
(`astro check`).

### Configuration

| Var | Scope | Purpose |
|---|---|---|
| `PUBLIC_SITE_URL` | public | canonical/OG base (e.g. `https://sentry.chipmo.mn`) |
| `SENTRY_BACKEND_URL` | server | where `/api/lead` forwards leads; unset = log to stdout (dev) |
| `PORT` / `HOST` | server | provided by Railway |

---

## Deployment

Target: **Railway** (Dockerfile + `railway.toml`). The Astro Node adapter (`mode: standalone`) builds a
self-contained `dist/server/entry.mjs`; the multi-stage Dockerfile ships a minimal Node-Alpine runtime
(non-root, healthcheck `/`). CI runs `astro check` + build; pushing to `main` auto-deploys via
`railway-deploy.yml`.
